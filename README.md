# Invitación de boda

pnpm install
pnpm dev        # desarrollo
pnpm build      # producción (carpeta dist/)

- Textos, fechas, fotos y lugares: src/data/boda.js
- Fotos: reemplaza los archivos de public/fotos/ (ver LEEME.txt en esa carpeta)
- Canción: copia tu archivo a public/musica/cancion.mp3
- Colores y tipografías: src/index.css (bloque @theme)
- Cada sección es un componente en src/components/
